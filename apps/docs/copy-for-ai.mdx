# Shugo Developer Context

**Overview:** Shugo is an on-chain guardrail for AI agents on Solana. It separates custody from execution authority.

**Key Concepts:**
- **Zero-Custody:** Agents sign with ephemeral keys.
- **Velocity Caps:** Max spend limits enforced on-chain per slot window.
- **UNKNOWN_INIT_ID:** Sentinel value (i64::MIN) used to prevent slot race conditions during initialization.

**Integration Example:**
```typescript
import { ShugoClient, UNKNOWN_INIT_ID } from "@shugo-protocol/sdk";

const shugo = new ShugoClient(connection, treasuryOwner);
await shugo.createAllowance({
  mint,
  owner: treasuryOwner.publicKey,
  agentDelegate: agentPublicKey,
  velocityCapAmount: 100_000_000n,
  windowSlots: 216_000n,
  initId: UNKNOWN_INIT_ID,
});
